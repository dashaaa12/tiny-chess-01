A chess engine in 4 KB of Python: negamax alpha-beta with a transposition table, PVS, quiescence search, and tapered piece-square evaluation with passed-pawn terms.
Fully deterministic: a fixed 130,000 nodes per move, no clock, no randomness, no model calls.

## Run it

```sh
python3 main.py
```
